# Brain — Tasks

Task specifications for ongoing feature work. The initial build is complete and all prior tasks have been retired.

**Lifecycle:** Create a task file in `active/` when work begins. Move it to `completed/` when merged. Use `backlog/` for scoped future work that isn't yet in progress.

**When to create a task file:** Any non-trivial feature, infrastructure change, or refactor — anything that spans more than one coding session or requires a planning phase before implementation.

**Format:** Each task file should include: goal, acceptance criteria, relevant specs or ADRs, and any known constraints.
